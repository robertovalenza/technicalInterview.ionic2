# Technical Test — Route Map App (Ionic + Angular)

## Task
As a user, I must be able to:
- See an interactive map centered on my current GPS position by default
- Type a destination address in a search box
- See the route from my current position to the destination on the map

Use **Ionic v8**, **Angular v17** and **Capacitor**.

### Notes
- You can use Google Maps (recommended) for:
  - Place Autocomplete (destination search)
  - Directions (route)
- Handle basic errors (permission denied, address not found).
